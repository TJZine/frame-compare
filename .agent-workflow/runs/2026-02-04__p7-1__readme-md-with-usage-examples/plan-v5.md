## Generator CLI Surface (Locked)

File: `scripts/generate_api_docs.py`

Required flags (exact names, tests depend on these):

- `--project-root <path>`: root directory of the project to scan.
  - Default: current working directory (repo root when run from repo).
- `--output <path>`: output path for generated Markdown.
  - Default: `<project-root>/docs/api.md`.
- `--check`: do not write; compare the would-be output against `--output`.

Exit codes (locked):

- `0`: output is up-to-date (or write succeeded).
- `2`: output missing or differs.
  - If `--check` and output file is missing, stderr MUST contain `MISSING: <path>`.
  - If `--check` and output differs, stderr MUST contain `STALE: <path> differs from generated`.
- `3`: missing docstrings for exported functions/classes (constants do not require docstrings).
  - stderr MUST include the missing symbol names (one per line is fine).
- `4`: invalid `__all__` shape (must be a literal list/tuple of string literals), or unresolved re-export target.
- `1`: unexpected/unhandled error (should be avoided; prefer deterministic messages + non-traceback output).

## Markdown Output Format (Locked)

The generator MUST produce deterministic GitHub-flavored Markdown with this structure:

1. Title + generated notice:
   - `# API Reference`
   - A blockquote line containing: `Generated by \`scripts/generate_api_docs.py\`. Do not edit manually.`

2. For each module in the locked module list (below), in order:
   - `## <module_name>`
   - The module docstring first paragraph (or empty line if absent).
   - For each exported symbol (case-insensitive sorted):
     - `### <symbol_name>`
     - For functions: a single backticked signature line: `` `<name>(<args>) -> <return>` ``
     - For classes: a single backticked line: `` `<ClassName>` ``
     - For constants: a single line: `` `<NAME>` — constant (<type>) ``
     - Followed by the docstring first paragraph for functions/classes only.

Docstring “first paragraph” rule (locked):

- Use the first paragraph of the docstring: strip leading/trailing whitespace; split on the first blank line.
- If no docstring exists for a function/class, it is considered missing (exit code 3 in `--check`).
- Constants do not require docstrings and never trigger missing-docstring failures.
