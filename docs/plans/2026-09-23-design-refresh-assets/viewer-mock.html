Report viewer: design refresh mockups

Static mockups for B1 (source identity), B2 (palette fade), B3 (Inspector and Report Information), and A4 (lens and palette details). Built with the viewer's real colour tokens and fonts; the image is synthetic. Numbers match the reviewed report.

1 · Viewer, Slider mode (B1, B2, A3, A4)

Toolbar: the pair control is two source selects joined by swap (no "L:", "vs", "R:"); selects are capped at 20rem and end-truncate (the release group goes first; the full name is in the tooltip and the open list); the offset status uses the UI face for its label and mono for the value. Stage labels: the standard name, then resolution and size; the separate HDR/SDR word is dropped because the name already states the HDR format. Palette: distinct icons (offset arrows vs gear), no "Fixed" text; shown here in its ghost state because the pointer is far away.
